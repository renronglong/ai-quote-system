## 铝锭价获取规则（必须执行）

**每次报价前，必须使用代码执行工具获取实时铝锭价**：

```python
import requests
from datetime import datetime

def get_aluminum_price():
    today = datetime.now().strftime("%Y%m%d")
    url = f"http://www.lvdingjia.com/zhishu/{today}.html"
    try:
        resp = requests.get(url, timeout=10)
        resp.encoding = "utf-8"
        html = resp.text
        import re
        # 匹配南海铝锭价（非灵通）
        match = re.search(r"南海(?!灵通).*?(\d+)~(\d+)", html)
        if match:
            avg = (int(match.group(1)) + int(match.group(2))) / 2
            return avg
    except:
        pass
    return 23530  # 默认值（2026年参考价）

price = get_aluminum_price()
print(f"今日铝锭价: ¥{price}/吨 = ¥{price/1000:.2f}/kg")
```

**禁止使用估算值**，必须实时获取。

## 报价计算公式

### 一、挤压铝型材（实心/空心）

#### 1. 截面面积计算
- **实心材**：外轮廓面积 - 倒角面积
  - 倒角面积 = 4 × (倒角尺寸² / 2)
- **空心材**：外轮廓面积 - 内腔面积 - 倒角面积

#### 2. 重量计算
```
米重 = 截面面积(mm²) × 2.7(g/cm³) / 1000 = kg/m
单件重量 = 米重 × 长度(m)
```

**重要区分**：
- **米重**：每米长度的重量（kg/m）
- **单件重量**：实际长度产品的重量（kg）

示例：截面840mm²，长度100mm
- 米重 = 840 × 2.7 / 1000 = 2.27 kg/m
- 单件重量 = 2.27 × 0.1 = 0.227 kg

#### 3. 成本计算
```
铝材费 = 单件重量(kg) × 铝锭价(元/kg)
       = 单件重量(kg) × (铝锭价(元/吨) / 1000)
```

#### 4. 挤压加工费
| 截面类型 | 单价 |
|---------|------|
| 实心简单截面 | 3元/kg |
| 空心简单截面 | 2.5元/kg |
| 复杂截面（多腔） | 4元/kg |

#### 5. CNC加工费（机时法）
```
机时费率 = 80元/小时
加工费 = (装夹时间 + 加工时间 + 检测时间) / 60 × 机时费率
```

**典型时间**：
- 装夹：1-3分钟/件
- 切割：实心材约1分钟，空心材约0.5分钟
- 去毛刺：0.5-1分钟/件

**参考报价**：
- 实心材切割+去毛刺：¥1.5/件
- 空心材切割+去毛刺：¥0.8/件
- 钻孔（Φ5-10mm）：¥0.3/孔
- 攻丝（M6-M10）：¥0.5/孔

#### 6. 表面处理费
```
表面积 = 截面周长 × 长度
```

| 处理方式 | 单价 |
|---------|------|
| 氧化本色 | 8元/m² |
| 氧化黑色 | 10元/m² |
| 喷涂 | 20元/m² |
| 电泳 | 15元/m² |

**注意**：倒角/圆角在挤压时已成型，不额外收费。

#### 7. 包装费与运输费
```
包装费 = 单件重量(kg) × 0.5元/kg
运输费 = 单件重量(kg) × 0.5元/kg
```

#### 8. 总报价
```
总报价 = 铝材费 + 挤压费 + CNC费 + 表面处理费 + 包装费 + 运输费
```

---

### 二、板材加工

```
材料费 = 整张板材价格 ÷ 可排版数量

排版数量 = floor(板材长/下料长) × floor(板材宽/下料宽)

每道工序累计（逐道叠加）：
  工序1成本 = (材料费 + 工序1加工费) × 1.03 × 1.03
  工序2成本 = (工序1成本 + 工序2加工费) × 1.03 × 1.03
  ...
  其中 1.03 × 1.03 = 每道工序叠加约6%的损耗+管理费

表面处理费 = 按面积计算 × 1.05（含5%附加）

总报价 = (最后工序累计 + 表面处理费) × 1.05 + 包装 + 运输
```

---

### 三、压铸（铝合金/锌合金）

```
材料费 = 单件重量 × 材料单价
模具费分摊 = 模具总价 ÷ 订单数量
压铸费 = 单件重量 × 压铸单价
  - 铝合金：3-5元/kg
  - 锌合金：2-4元/kg
CNC精加工 = 按机时法计算
表面处理 = 按面积计算

总报价 = 材料费 + 模具分摊 + 压铸费 + CNC费 + 表面处理 + 包装 + 运输
```

## 常见问答

**Q: 什么是米重？**
A: 米重是铝型材每米长度的重量，单位 kg/m。计算公式：截面面积(mm²) × 2.7 / 1000。

**Q: 实心材和空心材怎么区分？**
A: 看截面是否有内腔。DXF图纸中，如果只有外轮廓没有内腔轮廓，就是实心材。

**Q: 倒角需要额外收费吗？**
A: 挤压成型时倒角已经一次成型，不需要额外CNC加工，不收费。

**Q: 包装运输怎么算？**
A: 按产品重量计算，包装0.5元/kg + 运输0.5元/kg = 1元/kg。
